# 🔐 CyberProject

Application web éducative dédiée à la cryptographie et à la cybersécurité — Projet universitaire ENSI 2026.

## Stack technique

| Couche | Technologie |
|--------|------------|
| **Frontend** | React 18 + Vite + React Router + Lucide React |
| **Backend** | FastAPI (Python 3.10+) |
| **Communication** | REST API (JSON + fichiers multipart) |
| **Cryptographie** | RSA, ECC (Elliptic Curve Cryptography) |

---

## Lancement rapide

```bash
# Terminal 1 — Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

# Terminal 2 — Frontend
cd frontend
npm install
npm run dev
```

- 🌐 Frontend : http://localhost:5173
- 📄 API Docs : http://localhost:8000/docs

## Routes API

### RSA — `/api/rsa`
| Méthode | Endpoint | Description |
|---------|----------|-------------|
| `POST` | `/generate-key` | Génération paire de clés RSA |
| `POST` | `/encrypt-file` | Chiffrement de fichier (upload) |
| `POST` | `/decrypt-file` | Déchiffrement de fichier (upload) |
| `GET`  | `/current-key` | Clé active en mémoire |

### ECC — `/api/ecc`
| Méthode | Endpoint | Description |
|---------|----------|-------------|
| `POST` | `/generate-key` | Générer paire de clés (k, Q=k·G) |
| `POST` | `/encrypt-file` | Chiffrer fichier (ECIES + AES) |
| `POST` | `/decrypt-file` | Déchiffrer fichier avec clé privée |

### RSA Attack — `/api/rsa-attack`
| Méthode | Endpoint | Description |
|---------|----------|-------------|
| `POST` | `/factorize` | Factoriser n pour retrouver p et q |
| `POST` | `/wiener` | Attaque de Wiener (d petit) |
| `POST` | `/brute-force` | Force brute petit exposant |

### ECC Attack — `/api/ecc-attack`
| Méthode | Endpoint | Description |
|---------|----------|-------------|
| `POST` | `/bsgs` | Baby-step Giant-step |
| `POST` | `/pohlig-hellman` | Pohlig-Hellman |
| `POST` | `/anomalous` | Attaque courbes anomales |

## Règles de contribution

- ⛔ Ne jamais modifier : `main.py`, `App.jsx`, `main.jsx`, `index.css`, `Navbar.*`
- ✅ Toujours utiliser les variables CSS globales (`--navy`, `--accent`, etc.)
- 🌿 Travaillez sur votre propre branche :
```bash
git checkout -b membre-X-feature
```
- 🔁 Ne pas push sur `main` sans validation du groupe
- ⚠️ Format de réponse API recommandé :
```json
{
  "success": true,
  "steps": ["Étape 1...", "Étape 2..."],
  "result": {},
  "explanation": "..."
}
```
